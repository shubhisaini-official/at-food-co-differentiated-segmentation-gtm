## 📌 Executive Summary & Problem Statement

* **The Challenge:** Broad, generic targeting sentences fail to drive business impact. **AT Food Co.** needed a concrete customer strategy brief that evaluates Customer Lifetime Value (CLV), frequency, and recency across digital and offline touchpoints.
* **The Solution:** A **Differentiated Targeting Brief** that segments 600 customers into clear financial tiers and provides actionable, role-based execution lines for Buyers, Store Managers, and Media Planners.

## 🎯 2. Role-Based Actionable Brief (Primary Cohorts)

### Primary Cohort 1: Festive Gifters (Omnichannel Engine)
* **Buyer:** Stock mid-range gold/diamond gifting collections, gemstone pendants, and seasonal festive box sets (₹25,000–₹40,000).
* **Store Manager:** Set up dedicated "Festive & Anniversary Gifting" display counters near store entrances with ready-to-gift luxury packaging.
* **Media Planner:** Run Meta/Google ads targeting seasonal festival intent, anniversary milestones, and festive gifting lookalikes.

### Primary Cohort 2: Bridal Planners (High-Margin Anchor)
* **Buyer:** Stock complete heavy bridal sets, choker necklaces, and matching bangles with high-craftsmanship finishes and hallmark certifications.
* **Store Manager:** Set up private, appointment-only Very Important Person (VIP) bridal lounges offering personalized consultations and family trial sessions.
* **Media Planner:** Run high-impact visual campaigns on Instagram/Pinterest geotargeted around premium wedding venues and luxury zip codes.
